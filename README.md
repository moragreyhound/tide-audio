# Tide

Tide is a terminal music player for Python 3.11+. It streams and downloads
audio with `yt-dlp`, decodes through FFmpeg, plays via `sounddevice`, and
renders an animated Textual interface whose colors are derived from the
artwork of the current track.

## Requirements

- Python 3.11 or newer
- FFmpeg (decode and download)
- A working audio output device

## Install

### FFmpeg

Windows (WinGet):

```powershell
winget install Gyan.FFmpeg
```

Tide auto-detects the WinGet install location even if your `PATH` is stale,
so a terminal restart is not required.

macOS (Homebrew):

```bash
brew install ffmpeg
```

Debian / Ubuntu:

```bash
sudo apt install ffmpeg
```

Fedora:

```bash
sudo dnf install ffmpeg
```

Verify with `ffmpeg -version`, or run `python -m tide doctor` to have Tide
check for you.

### Python packages

```bash
pip install textual yt-dlp ffmpeg-python sounddevice numpy Pillow platformdirs tomli-w
```

`sounddevice` ships its own PortAudio build on Windows and macOS. On Linux,
install the system library if the import fails:

```bash
sudo apt install libportaudio2
```

## YouTube cookies (cookies.txt)

Some videos need a signed-in session (age-restricted, members-only, higher
request limits). Tide reads a Netscape-format `cookies.txt` and passes its
path to yt-dlp. The file contents are never logged.

Tide looks for `cookies.txt` in this order:

1. The directory you run `python -m tide` from (put it here)
2. The config directory (`python -m tide doctor` prints it)
3. The data directory

### Export cookies with the bookmarklet

1. Open <https://www.youtube.com> in your browser and sign in.
2. Create a new bookmark (right-click the bookmarks bar, "Add page" or
   "Add bookmark"). Name it anything, e.g. `Tide cookies`, and paste the
   entire line below into the URL field:

```javascript
javascript:(function(){function g(n){var c=document.cookie.match("(^|;)\\s*"+n+"\\s*=\\s*([^;]+)");return c?c.pop():""}var domain=location.hostname;if(!domain.includes("youtube.com")){alert("Please run this script while on youtube.com");return;}var cookies=document.cookie.split("; ");var netscape="# Netscape HTTP Cookie File\n# http://www.match2000.at/rubriken/edv/cookiefile.htm\n# This file was generated by a bookmarklet.\n\n";cookies.forEach(function(cookie){var eqPos=cookie.indexOf("=");var name=eqPos>-1?cookie.substr(0,eqPos):cookie;var value=eqPos>-1?cookie.substr(eqPos+1):"";netscape+=".youtube.com\tTRUE\t/\tFALSE\t0\t"+name+"\t"+value+"\n";});var blob=new Blob([netscape],{type:"text/plain"});var a=document.createElement("a");a.href=URL.createObjectURL(blob);a.download="cookies.txt";document.body.appendChild(a);a.click();document.body.removeChild(a);})();
```

3. Stay on the youtube.com tab and click the bookmark. The script writes a
   Netscape cookie file and downloads it as `cookies.txt`.
4. Move `cookies.txt` into the directory you run Tide from (the project
   folder). That is all: Tide picks it up automatically.

If playback still fails with a sign-in or age message, the export is missing
cookies your browser keeps hidden from pages. Either sign in and re-run the
bookmarklet, or set `cookies_from_browser` in `config.toml` (for example
`cookies_from_browser = "chrome"`) so yt-dlp reads the browser profile
directly.

`cookies.txt` is a login credential. Do not commit it, share it, or copy it
into logs and bug reports.

## Run

Start the player with a URL:

```bash
python -m tide play "https://www.youtube.com/watch?v=..."
```

Local files work too:

```bash
python -m tide play "C:\Music\track.mp3"
```

`--art` embeds cover art in the visualizer:

```bash
python -m tide play "https://www.youtube.com/watch?v=..." --art
```

## Commands

```bash
python -m tide play <url>            # play immediately (opens the interface)
python -m tide search "query"        # search YouTube
python -m tide search "query" --json # search, JSON output for scripts
python -m tide download <url>        # download a track or playlist
python -m tide download <url> --art  # download with embedded cover art
python -m tide playlist list         # list saved playlists
python -m tide playlist new <name>   # create a playlist
python -m tide playlist import <f>   # import an .m3u file
python -m tide playlist export <n>   # export a playlist to .m3u
python -m tide playlist delete <n>   # delete a playlist
python -m tide doctor                # check Python, FFmpeg, audio, config
python -m tide --version             # print the version
```

## Keys

Press `F1` inside the app for the full list. The common ones:

| Key | Action |
| --- | --- |
| `space` | Play / pause |
| `n` / `p` | Next / previous track |
| `left` / `right` | Seek 5 seconds (`shift` for 30s) |
| `+` / `-` | Volume |
| `m` | Mute |
| `/` | Search |
| `enter` | Play the selected row |
| `a` | Add the selected row to the queue |
| `d` | Download the selected row |
| `1` / `2` | Queue / Library view |
| `v` | Cycle visualizer mode |
| `ctrl+b` | Show or hide the playlist rail |
| `D` | Show or hide downloads |
| `o` | Open a URL |
| `q` | Quit |

Keys are remappable in `keys.toml` next to `config.toml`.

## Configuration

`config.toml` lives in your platform config directory (run
`python -m tide doctor` to print it). Every key has a safe default, and an
invalid value falls back to that default instead of blocking startup. Useful
keys:

```toml
ffmpeg_path = ""            # override the FFmpeg binary location
cookiefile = ""             # explicit cookies.txt path (auto-detected when empty)
cookies_from_browser = ""   # e.g. "chrome", "firefox" - reads the browser profile
proxy = ""                  # proxy URL passed to yt-dlp
music_dir = ""              # where downloads are saved
```

Environment overrides: `TIDE_FFMPEG_PATH`, `TIDE_COOKIEFILE`,
`TIDE_MUSIC_DIR`, `TIDE_CONFIG`, `TIDE_CONFIG_DIR`, `TIDE_DATA_DIR`,
`TIDE_CACHE_DIR`.

## Motion and color

The visualizer and ambient palette transitions follow the `motion` setting
(`full`, `reduced`, `none`). `NO_COLOR` and `TIDE_REDUCE_MOTION` are honored.
Logs are written to a rotating file under the data directory and never to the
terminal.
